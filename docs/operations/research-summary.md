# 調査のまとめ

運営者の体験を設計するために行った調査の一覧と、設計に効いた発見である。
各報告は [research/](research/) にある。実在の個人名とアカウント名は含めていない。

| 報告 | 対象 | 設計に効いた発見 |
|---|---|---|
| [R1](research/R1-existing-tools.md) | 既存の大会運営ツール(Ultimate Central、Tournify、Challonge、TONAMEL など) | 段の連結(予選 → 決勝)と「各プールから何チーム」という宣言が共通の設計。確定ボタンで次の段へ進める。勝者入力・相手承認に各社が収束 |
| [R2](research/R2-ultimate-operations.md) | アルティメットの大会運営の実務(USAU、WFDF、JFDA、当日の事故) | JFDA のタイブレーク手順と再帰適用。当日の事故(スコア改ざん、システム障害、人数不足、暑さ、雷)と対処。運営設定の 19 項目 |
| [R3](research/R3-client-formats.md) | 運営会社自身の 348 大会の実データ | 3 テンプレートで 97.9%。プール順位は勝ち点 → 得失点差 → 得点で 56 プール全一致。試合番号と試合順の規則。試合間隔は大会ごとに 15〜90 分 |
| [S1](research/S1-japan-voices.md) | 国内の利用者の声(第 1 回。取得経路の制約で 19 件) | アプリが落ちる・重い、順位の計算が不正確、入力ボタンの配置が悪い |
| [S3](research/S3-spreadsheet-ops.md) | 表計算で大会を運営している人の工夫と困りごと(44 件) | 同率の処理(19 件)、勝ち上がりの転記(13 件)、スコアの集計と共有(15 件)が上位 |

収集中の調査(国内の声の再収集、海外の声)は、まとまり次第ここに加える。
Reddit と X は自動での取得を拒否しているため、回避せず対象から外している。必要なら公式 API の利用を検討する。
