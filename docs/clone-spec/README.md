# 参照サイト調査(clone-spec)

score.clubjr.com を 2026 年 10 月 21 日に調査した記録である。
実際に取得した HTML、CSS、JavaScript を読んで確認した事実と、根拠つきの推定(「推測」と明記)を分けて書いている。
閲覧ページの実装は、この記録を仕様として扱う。

| 章 | 対象 |
|---|---|
| [A](A-frame-top-teamlist-gallery.md) | 共通の外枠(ヘッダー、大会ナビ、サイドバー、フッター)、CSS の値、大会一覧、大会トップ、チーム一覧、ギャラリー、エラー画面 |
| [B](B-schedule.md) | スケジュール(絞り込み、ソート、行の状態、未確定チームの表記、表示幅の切り詰め) |
| [C](C-standings-groups.md) | ディビジョン成績、グループ成績(総当たり、トーナメント表)、順位の決まり方 |
| [D](D-team-match-player.md) | チーム、試合、選手の各ページ |
| [E](E-catalog-variants.md) | 全 348 大会の分類、ナビの 7 パターン、競技と年代による違い |

調査で取得した生データ(実在の選手名を含む)は git 管理外の `.local/survey-raw/` にあり、全大会の分類結果は `.local/E_catalog.json` にある。
本文中の `$S/raw/...` というパスは、調査時の作業ディレクトリでのパスであり、`.local/survey-raw/...` に読み替える。
実在の個人名は本文から伏せ字にした。
