## 10. 補足: 気づいた細部

- 大会名の `<title>` は `[CJS] {大会名}`(一覧は `[CJS] ClubJr大会一覧`)。
- ナビのリンクはすべて絶対URL `https://score.clubjr.com/pscore/…?lang=jp`。大会トップ・ディビジョン行のリンクは `<a href="#" onclick="document.location = '…'; return false;">`(JS必須)、ナビ内は通常の `<a href>`。模倣では href に実リンクを置く実装で挙動は同等。
- グループ成績ページに画像だけのものがある: ID 6539(Temporary ranking)は `div.TBL` の中に `<img src="/zfiles/ScoreViewGrp/…jpg" style="width:500px;height:695px">` のみ(301バイト、タイトルの `SCV_MIDA_M` + 画像)。名称が `Temporary ranking` の63グループが同種の可能性が高い(推測。1件のみ実確認)。
- 受付中の大会トップには、ディビジョン行はあるが試合データが未登録のため、[スケジュール] は出ても中身は空の表になる。
- 大会トップは1枚あたり 約23〜40KB。大会数は348、取得にかかったのは約7分(1.2秒間隔)。

## 11. 結論: 模倣実装で対応すべきページ種別とバリエーション

### 共通レイアウト(全ページ共通)
- 共通ヘッダ(ロゴ画像・SNSアイコン5個・会社リンク・4項目ナビ)、フッター(Copyright)、背景画像 def_bgimg.png(大会ページ)と黒背景(一覧ページ)。
- `ul#score_navi` ドロップダウン(jQuery 1.7.2 + jquery.dropdown 相当をそのまま再現 or 同等の CSS/JS 実装)。
- 左サイドバー `#sub`(枠画像つき、バナー0〜30個)。大会ごとのバナー画像リスト(`/zfiles/ScoreViewTop/*`)をデータに持つ。

### ページ種別
1. 大会一覧 /sctnmt: 3見出し(エントリー受付中 / エントリー締切り / 大会終了)と大会リンク348件。
2. 大会トップ /scview/{ID} と /pscore/scv_top/open/{ID}: 名称・ロゴ・ディビジョン表・自由記述HTML(リッチテキスト・画像・オレンジのバッジ)。
3. チーム一覧 scv_team_list: チーム戦(リンクあり、`-- N Teams --`)と個人戦(リンクなしの選手名、`-- N Players --`)の2形式。
4. スケジュール(全ディビジョン scv_search_tn / ディビジョン別 scv_search_div): 検索フォーム + ソート可能な試合表(`MC_*` 状態クラスと種別クラス)。
5. ディビジョン成績 scv_division: 順位表 + スコアボードリーダー(+ ブロック)。旧様式は SOTG ランキング表。空データ(全0、順位空欄)の形も必要。
6. グループ成績 scv_group: リーグ型(順位表 + 結果一覧)、トーナメント型(ブラケット表 `TN_TMPL`)、画像のみ型(Temporary ranking など)の3形式。
7. ギャラリー scv_tgallery: タイトル + 画像群(`SCV_MIDA_M` + `CM`)。
8. チームページ scv_team、選手ページ scv_player、試合詳細 scv_match(担当外のページ。ただしDG個人戦では1人チームとして scv_team を持つ)。

### バリエーション(データ駆動で必要なもの)
- ナビ: 7パターン(3章)。ラベル `チーム一覧/エントリー一覧`、`グループ成績/成績` の切り替え、スケジュール/ディビジョン成績の有無、ギャラリーの有無と個数(0〜14)、リンクの無いグループ(名称のみ `<p>`)、幅調整用の空 li(172/321/495px)。
- ディビジョン行のリンク状態: 両方あり / スケジュールのみ(最終順位が Dummy_Link) / 両方 Dummy_Link の3通り。
- 大会状態: 受付中 / 締切り / 終了、および名称に付く中止表記。
- ロゴ: 大会固有画像 330 / 既定画像 18。自由記述: 空 118 / 有り 230(うち画像入り 168)。
- 競技: アルティメット / 4on4 / ビーチ / 5人制 / ディスクゴルフ(個人・チーム・ダブルス) / フリースタイル / ビーチ+フリースタイル併催。ドッヂビー・ガッツは存在しない。DG・フリースタイルのスコア表示は無く、空のテンプレートまたは隠しページ。
- グループ名: 563種の表記ゆれを原文のまま保持(誤記 `Tounament`/`1th placement`/`placemnet`、全角数字、ひらがなリーグ名を含む)。
- 年代差: 2017〜2018年のグループ表は scv_match リンクなし・ブロック表なし、2020年前後の SOTG 表、369 以降のギャラリー、2022 以降の「４人制部門」名。
- シリーズ物は大会ごとに独立したページ。大会間リンク・通算ページは作らなくてよい(通算は自由記述の文章のみ)。
